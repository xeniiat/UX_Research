# UX-исследование: Customer Journey Map пользователя Tripster

## О проекте
Данный репозиторий содержит результаты UX-исследования, посвященного анализу пользовательского опыта (Customer Journey Map) для сервиса онлайн-бронирования экскурсий [**Tripster**](https://experience.tripster.ru/).

зу пользовательского опыта для сервиса онлайн-бронирования экскурсий **Tripster**. В рамках исследования были разработаны два ключевых артефакта:

*   **Персона** — типизированный портрет целевого пользователя, основанный на качественных данных о его целях, потребностях, болях и поведении.
*   **Customer Journey Map (CJM)** — визуализация пути пользователя на всех этапах взаимодействия с сервисом: от поиска экскурсии до получения впечатлений после её завершения.

**Цель исследования**: Объединить персону и CJM, чтобы выявить ключевые болевые точки и точки роста на всех этапах взаимодействия пользователя с сервисом: от поиска экскурсии до получения впечатлений после ее завершения. Определить уже существующие в сервисе решения и предложить новые решения для незакрытых болей.

## Методология
*   **Методы сбора данных**:  
    *   Глубинные интервью с потенциальными пользователями.  
    *   Анализ существующих отзывов.

*   **Этапы работы**:  
    1.  Сбор и синтез данных → создание персоны.  
    2.  Построение CJM на основе персоны и выявленных сценариев.  
    3.  Выявление инсайтов, проблем и возможностей для улучшения.

*   **Инструменты**:  
    *   Figma – для визуализации персоны и CJM.  
    *   GitHub – для хранения и публикации результатов.

## Как использовать этот репозиторий
1.  Прочитайте `README.md`, чтобы понять общую структуру и цели исследования.  
2.  Изучите **персону** (изображение в `assets/persona.png` или макет в Figma) – это поможет вам понять, для кого именно строилась карта пути.  
3.  Перейдите к **Customer Journey Map** (`assets/cjm-tripster.png` или Figma-макет) – здесь показан полный путь пользователя с выделенными болевыми точками и возможностями.
